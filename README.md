# Инструкция по запуску

## Клиент:
```bash
  cd client
  npm i
  npm run dev
```

## Сервер:
```bash
  cd server
  npm i
  PORT=8080 npm run start
```
# Принятые решения
## react-hook-form + zod

Для работы с формой я использовал `react-hook-form` вместе с `zod`. Это позволило:

- удобно управлять состоянием формы;
- добавить понятную валидацию;
- сократить количество лишнего кода;
- сделать формы более предсказуемыми и типобезопасными.
